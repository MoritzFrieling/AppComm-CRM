# Definition of Done

## A feature is DONE whenever the below listed requirements are met.

- It has been implemented in a test-driven way
- It fulfills all of the requirements of the customer.
- It has been reviewed and tested by a t least another person on the team (four eyes principle)
- It has passed all of the predefined tests
- It has been merged successfully into the development branch
- It has been moved to DONE in the sprint board
