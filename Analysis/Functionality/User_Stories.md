# User Stories
All User Stories in braces [] have not been started yet due to prioritization, but are planned for future iterations.


### As an admin I want to be able to...
1. Customer
- see all the customers to get a good overview.
- add a customer if there is a new customer for AppComm.
- view, edit or delete an existing customer to manage them, possibly if there has been a change.
- (De)activate a customer to enable/ disable access.
- [add a quick note for a specific customer to quickly write something down.]
2. Contact Person
- add a contact person related to a specific customer if there is a new resonsible person.
- view, edit or delete a contact person related to a specific customer to manage them, possibly if there has been a change.
3. Solution
- see all the solutions to get a good overview.
- add a solution (services, products, hosting plans and domain names) and its price for that to the system if a new solution exists.
- view, edit or delete a solution within the system to manage existing solutions.
- assign or unassign a solution to a customer to keep an overview of which customer has which solutions.
- [get notified when a customer has a problem with one of their products or services to deal with this problem.]
- [set the current status of a solution for customer visibility.]
- [upload a new invoice to a customer, so they can keep track of their expenses.]
4. Tickets
- (Un)assign a GitLab project from/to a customer so that potential tickets can be created.
- Write a ticket for a solution so that potential features can be implemented and issues can be solved.
- [see all the tickets from all customers to see if there are any problems that need to be solved.]
- [see previous invoices of a customer to have a better overview of their expenses.]

### As a customer I want to be able to...
1. Solutions
- [see all my solutions (services, products, hosting plans and domain names) and their prices in one place to have a better overview.]
- [see the progress of my products to know how far they are.]
- [see what kind of products were build for me and what they are for to have a better overview.]
- [see my previous invoices to have a better overview of expenses.]
2. Ticket
- [create new tickets when I have a problem with my products or services to get help more quickly.]

### As a user (Admin and customer) I want to be able to
1. Ticket
- [write comments on a ticket to communicate with the other part.]
- [see the comments and status on a ticket to know the progress.]
- [set a ticket to solved when the problem is solved.]
2. Chat
- [chat with the other party to have a more informal way of communicating.]
3. Account
- [log in and out to be able to use the system the way it is intended.]
